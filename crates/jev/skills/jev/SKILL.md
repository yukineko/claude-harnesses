# /jev — advisory な型付き判定

jev はテキストを生成せず、**型付き・較正済みの判定**を返すモデル
（TypeSafe AI の "System One"）。このスキルはそれを **advisory としてのみ**使う。

## 最初に読むこと — 使ってよい用途と、絶対に使わない用途

**jev は外部のクローズドなクラウド API** である。CLAUDE.md 第7節により、
**流れを止める/通す権限を渡してはならない**。

| 使ってよい | 使ってはいけない |
|---|---|
| 候補の**並び順**を決める（重大度・関連度・影響度） | ゲートの block/allow を決める |
| **重複検出**（これは既出の finding か？） | テストや check の合否を決める |
| **タグ分類**（既知の分類語彙への振り分け） | 「問題なし」の根拠にする |
| 人間に見せる**注記・理由文**を書く | 判定不能を埋める |

**「jev が大丈夫と言った」を根拠に何かを ok にすることは禁止。** jev の答えは
予測であって観測ではない（CLAUDE.md 第2節）。`Advice` 型に `Clean` が無いのは
この禁止を型で表現したものである。

## 手順

### 1. 使えるか確認する（判定不能を「使える」に丸めない）

```bash
jev check
```

- **exit 0** → 使える。
- **exit 1** → `TYPESAFE_API_KEY` が無い（観測された不在）。**これは正常状態**。
  jev を使わずに元の手順をそのまま進める。「jev が無いので判断できない」と
  報告してはいけない — jev は最初から無くても成立する設計である。
- **exit 10** → 可用性が**判定不能**（env が非 UTF-8 等）。使わず、
  **その事実をユーザーに報告する**（1 と混同しない。環境が壊れている可能性がある）。
- **exit 127** → バイナリが配布されていない。結果は UNKNOWN。報告する。

### 2. 問いを組む

3 プリミティブから選ぶ。**1 回のリクエストに複数問を入れてよい**
（並列評価されるのでレイテンシはほぼ変わらない）。

- **Noul** — 「これは真か？」→ 確率 0–1。`criteria` 任意。
  **`0.5` は「中程度」ではなく「等確率」**。スペクトラムには使わない。
- **Choice** — 1 つ選ぶ → `choice` + `probabilities` + `confidence`。
  `criteria` は必須 map（選択肢名 → 説明、最大 255）。
- **Score** — 順序付きルーブリック上の位置 → `score` + `legend` + `confidence`。
  `criteria` は必須 array（2–10 段）。

```bash
printf '%s' '{
  "state": {"finding": "<調べたいテキスト>"},
  "questions": {
    "dup": {"type":"noul","instructions":"Is this the same defect as the one in prior_findings?"},
    "severity": {"type":"score","instructions":"How severe is this?","criteria":["cosmetic","annoying","breaks a workflow","data loss"]}
  }
}' | jev ask
```

### 3. 答えを使う（上げる方向にだけ）

- 高い確率 / 高いスコア → **順位を上げる・人間に警告する・注記を添える**。
- 低い確率 → **何もしない**。「安全だと確認できた」として扱わない。
- `jev ask` が非 0 → 答えは無い。**元の決定論的な手順の結果をそのまま使う**。

### 4. 落とし穴（答えを信じる前に）

- **数え上げ**は規模とともに誤差が増える → コードで数える。
- **日付演算**は不可 → Choice で年月日を抽出してコードで計算。
- **同じ問いを Noul と Choice で聞くと不整合**（否定の和が 1.0 にならない）→ 混ぜない。
- **敵対的テキストは答を動かす** → 攻撃者が書けるテキストの分類を単独で信じない。
- モデルは**字面どおり**答える → 意図ではなく言葉を書く。
- **`jev-latest` はドリフトする** → 閾値を調整するなら `~/.jev/config.toml` で
  `model` を具体版に固定してから。

### 5. 支出を確認する

jev は**課金される**（入力 $0.042/M tokens、出力無料。測定 2026-10-02）。

```bash
jev ledger   # 件数・トークン・推定 USD
```
