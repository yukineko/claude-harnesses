---
name: difflog
description: difflog のセッションログから開発者向けの変更ナラティブ（「何をどう変えたか」「なぜか」を一枚にまとめたもの）を作りたいときに使うこと。
argument-hint: [--session <id>] [--all]
allowed-tools: Bash(difflog:*), Read
---

ナラティブは生成のみとし、ログファイルを書き換えることは禁止。

ログが見つからない場合はナラティブを作らず、ログが無いことを報告すること。

1. `difflog last` で直近のログを取得（引数に `--session <id>` があれば `difflog list` から探す）。
2. ログに **Commits / Files changed / Stat / Diff** セクションがあれば、それを読むこと。
3. 日本語・エンジニア向けに、以下の構造でナラティブを出力すること。

```markdown
## セッションサマリ — <date>

**変更の概要**: <1〜3文で何を実装・修正したか>

**主な変更点**:
- <ファイル名>: <何を変えたか・なぜか>
- …

**コミット**:
- <sha> <message>

**残課題** (あれば): <次にやること、ブロッカー>
```

4. ナラティブは Markdown で出力すること。スキャンで読める分量に、コードブロックや詳細は最小限にすること。
5. ログに diff body がある場合、コードの変更意図を読み取って「なぜか」の説明を補足すること。
6. コスト節約のため、diffbody が大きい場合は stat と name-status だけ読んで概要を書くこと。
